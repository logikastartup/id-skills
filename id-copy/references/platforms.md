# platforms — per-surface norms (Indonesian market)

`component: SHARED` · `version: 1 (2026-10-31)`.
Register follows **business type + message type**, not the platform alone
(the reconciliation three template-sources force — see register.md).

## Marketplace store/product copy (Shopee/Tokopedia)

- Store "about" copy is **kami-led, formal-leaning — almost no Kak**
  (real store descriptions: "Selamat datang di toko kami…", "ALL ITEM READY
  STOCK", numbered policy lists, one emoji closer; 0/5 real examples used
  Kak — [Golocad](https://golocad.com/id/insights/contoh-deskripsi-toko-shopee-yang-menarik)).
- Product descriptions: informative three-part structure (what/specs/policy),
  ≥60 chars; Shopee's own seller guides push information over personality
  ([Seller Edu](https://seller.shopee.co.id/edu/article/1911)).
- Chat inside the same shop is a DIFFERENT register: Kak greetings, Anda
  product-info, kamu order updates ([Jubelio](https://jubelio.com/6-contoh-auto-reply-chat-shopee-bantu-tingkatkan-penjualan)).
  Don't homogenize them.

## Marketplace chat / auto-reply

- 1-3 sentences. Emoji in greetings only (😊), not in status lines.
- Patterns that read native: "Halo Kak 😊!", "Pesan Anda akan segera kami
  jawab sesuai urutan.", "Resi pengiriman akan diperbaharui secara
  otomatis", queue promises, WIB hours.
- CTAs: "Ada yang bisa kami bantu", keyword replies ("ketik INFO"), catalog
  checks.

## WhatsApp Business

- **Corporate/service suites:** Anda + kami, zero graphic emoji (text
  emoticons at most), 1-2 sentences, EVERY message ends in a CTA, bracket
  placeholders — "Stok [Nama Produk] terbatas. Selesaikan pesanan di
  keranjang Anda sebelum kehabisan." ([Qiscus](https://www.qiscus.com/id/blog/contoh-kalimat-pesan-otomatis)).
- **Seller-run shops:** Kak + playful warmth, regional variants exist and
  land (Bunda/Ayah for parent shops, Akang/Teteh Sundanese, Ukhti for
  modest-fashion) — "Halo, Bunda/Ayah… Sedang cari mainan apa nih untuk si
  kecil?" ([Kitalulus](https://www.kitalulus.com/blog/bisnis/contoh-pesan-otomatis-whatsapp-bisnis)).
- Pick the family by who runs the account; don't blend them.

## IG captions

- First line = hook (it's all that shows before "more"); storytelling
  middle; CTA close; hashtags after, not inside the sentence.
- Register matches the audience: mass-casual vs professional-formal —
  Indonesian caption practice agrees on hook + value + CTA
  ([QLAusa](https://www.qlausa.com/journal/rahasia-membuat-caption-instagram-menarik-yang-memikat-audiens));
  formulas in circulation: PAS, Hook-Value-CTA, AIDA
  ([SlideShare](https://www.slideshare.net/slideshow/5-powerful-instagram-caption-formulas-to-boost-engagement/288741749)).
- "Link di bio" is the standard CTA convention (no citable ID source
  found — treat as common knowledge, verify by browsing any ID brand
  account).

## Taglines (the craft, from documented campaigns)

- **Colloquial particles do the persuasion:** Tokopedia #MulaiAjaDulu —
  "aja… dulu" turns an imperative into an offhand shrug
  ([mix.co.id](https://mix.co.id/read/34656/flock-garap-kampanye-mulaiajadulu-dari-tokopedia)).
- **Coined words carry identity:** Gojek "Cerdikiawan" (cerdik + kiawan)
  under #PastiAdaJalan; santai register as deliberate brand strategy
  ([Marketing-Interactive](https://www.marketing-interactive.com/gojek-releases-a-dozen-creative-videos-as-part-of-its-cerdikiawan-campaign)).
- **First-person possessive claims the craving:** "Indomie, seleraku!" —
  the brand speaks AS the consumer's taste (UPI journal analysis; Scribd
  copywriting analyses).
- **Formal Anda anchors trust:** BCA "Senantiasa di Sisi Anda" — the bank
  register exists because it sounds like a bank.
- ⚠️ Verified only: use campaigns above. ("Apapun masakannya…" could NOT be
  verified as Bango's; documented Bango slogan is "Karena Rasa Tak Pernah
  Bohong" — attribution unstable, don't cite.)

## Cross-surface law

One brand, several registers, chosen per message job — greeting (warm),
information (neutral-clear), confirmation (kamu/short), tagline (craft).
The wrong move is one averaged voice everywhere.
