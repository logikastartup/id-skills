## Register + format

- **Register range: gaul hybrid (level 4–5), SPOKEN register.**
  Intra-utterance Indonesian-English code-mixing is the documented
  Gen-Z TikTok norm, functioning as identity/humor/prestige (peer-
  reviewed: Sarasvati 2025) — not a codeswitch error to fix here.
- **Script skeleton:** hook lands in the first seconds (documented
  window taught as 3–5s — third-party doctrine, no official TikTok ID
  guidance exists), then context → payoff → CTA. A caption is context,
  not prose.
- **Caption limits:** ≤2,200 characters; **keywords in the description
  matter more than hashtag spam** (2024+ Indonesian guidance — this
  advice FLIPPED from the 2021-2023 "#fyp #viral" era; date-stamp any
  hashtag advice you rely on).
- **Algorithm signals (documented):** interactions with similar
  content, likes, comments, shares, watch time — so end on a question
  the viewer can answer in three words, and make the first seconds
  survivable (Eraspace, 2024).

## TikTok-specific tells

- **Staged "POV:" hook with no payoff** — the format's #1 sin.
- **"Jangan lupa like dan subscribe"** — YouTube reflex; wrong
  platform, instant tell.
- **Corporate baku caption** on a gaul platform — reads like an
  institution wearing a costume.
- **Emoji piles** — one lands, five is a flyer.
- **Engagement-bait vs question-CTA:** manipulative begging ("tag 3
  teman!", "comment if you setuju") is a documented anti-pattern
  (Meta demotes it, rule applies to Indonesian posts — extrapolated to
  TikTok on the same logic; no TikTok-specific demotion doc found); a
  question the
  viewer *enjoys answering* ("setuju gak?", "mana nih yang...") is the
  platform's native idiom. The difference is whether answering costs
  the viewer anything.
